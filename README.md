# airtel-xstream-hsw4026atl-research
Security and hardware research on the Airtel XStream Smart Box (Vantiva-Technicolor HSW4026ATL). Covers Linux conversion feasibility, Vantiva OSS kernel analysis (Linux 4.9 / BCM72604), firmware history, conversion blockers, and a read-only local diagnostic dashboard with CSRF protection and enforced private-network scope. No device writes performed.
